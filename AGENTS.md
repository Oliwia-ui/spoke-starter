# Spoke

Spoke is a bike repair booking app. The designs live in Figma; this repo is the build.

- Build UI from Figma through the Figma MCP server. Work from frame links, not screenshots.
- Use the tokens in src/styles/tokens.css. No hardcoded colours, spacing or radius values.
  (tokens.css is created in step 5 of the class exercise.)
- Reuse components in src/components before adding new ones.
- Name components after their Figma component.
- Read DESIGN-SYSTEM.md before building. It lists every token, component spec, screen and
  Figma node ID. Update its build status table when you add a component or screen.
